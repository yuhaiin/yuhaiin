# Native OpenVPN local benchmark — 2026-10-11

Stock OpenVPN 2.6.20 in a rootless Podman container (Alpine 3.22, OpenSSL
3.5.9). Native yuhaiin Go client runs in an independent host process with its
in-process gVisor stack. Independent Python TCP/UDP echo workers run inside the
server container, reached at 10.88.0.1 through the encrypted tunnel. Outer
transport uses published loopback ports; container networking still crosses the
host/container boundary. AMD Ryzen 5 5600G, linux/amd64, Go 1.27.2, 1400-byte
client inner MTU, dual-stack address negotiation. Race instrumentation is used
for correctness tests, then disabled in the separate benchmark executable.

TCP transfers 16 MiB in each iteration with concurrent send/receive. Reported
MB/s counts application bytes in **one direction**; echo carries the same bytes
back. Three samples per case, two-second benchmark duration. UDP sends one
1200-byte datagram and waits for its matching echo before the next; this measures
round-trip latency and does not measure maximum UDP throughput.

| Outer transport | Control protection | Data cipher | TCP median MB/s (range) | UDP median round trip µs |
|---|---|---|---:|---:|
| udp | tls-crypt | AES-256-GCM | 33.39 (32.70–40.06) | 106.5 |
| tcp | tls-crypt | AES-128-GCM | 58.35 (57.86–59.28) | 117.0 |
| udp | tls-auth | CHACHA20-POLY1305 | 36.60 (33.28–37.47) | 108.4 |
| udp | none | AES-256-GCM | 35.95 (31.26–37.36) | 106.5 |

All four cases passed real-server IPv4/IPv6 TCP and UDP egress, keepalive beyond
the server ping-restart interval, untrusted CA and wrong-password rejection,
full reconnection, and three manual rekeys preserving an existing TCP socket.
The final plain-control case also uses username/password without a client
certificate. These are local tunnel measurements, not remote encrypted-link
capacity; no performance claim against another VPN protocol follows from them.

The final race-enabled correctness matrix extends manual rekey coverage to nine
rotations in each case and adds a two-second server renegotiation case. The fifth
case completed 11 server-initiated rekeys while preserving one TCP connection.
See the [final interop output](data/openvpn-interop-2026-10-11.json); no timing
samples from that aggressive renegotiation case enter the table above.

Reproduce:

```sh
python3 scripts/bench/openvpn/run.py --runtime podman --benchmark \
  --output /tmp/openvpn-results.json
```
